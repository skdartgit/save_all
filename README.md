# Save All

Android application built with:

- Kotlin
- Jetpack Compose
- Gradle 9.5.0
- JDK 17
- Android Gradle Plugin 9.3.0
- GitHub Actions

## Main Features

- 6 digit PIN authentication
- My Notes
- My Accounts
- My Files
- Export All Data
- Restore All Data
- Android Storage Access Framework
- Control Panel
- Delete selected Notes
- Delete selected Accounts
- Delete selected Files
- Reset App PIN

Default PIN:

123456
